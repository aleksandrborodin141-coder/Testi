# Changelog

Все важные изменения этого проекта будут документированы в этом файле.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-23

### Added
- Инициальный релиз TasteWay Beta 0.1
- AI-рекомендации заведений на основе предпочтений пользователя
- Интерактивная карта с Yandex Maps
- Поиск заведений по локации и категориям
- Система оценок и отзывов
- Сохранение избранных мест
- Профиль пользователя с историей посещений
- Безопасная авторизация через JWT
- Кэширование данных через SQLite
- Темная и светлая темы
- Поддержка русского языка

### Fixed
- Оптимизирована работа карты на слабых устройствах
- Исправлены проблемы с геолокацией на Android 12+
- Улучшена стабильность API соединения

### Known Issues
- Карта может медленно загружаться на слабом интернете
- Некоторые шрифты могут отображаться неправильно на старых устройствах

## [0.1.0-beta.1] - 2026-07-23

### Added
- Beta версия приложения для тестирования
